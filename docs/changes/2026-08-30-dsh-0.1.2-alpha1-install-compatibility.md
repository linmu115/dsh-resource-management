# 0.3.5 — DSH 0.1.2-alpha.1 installation compatibility

DSH, Cordis, Better Sidebar, React, and React DOM peers use `*`; optional peers remain optional. The plugin therefore does not reject the alpha.1 profile or experimental plugin combinations at install time.

This is an installation-policy change, not an adaptation to a removed alpha.1 runtime API. Runtime compatibility remains capability-driven, and the 0.3.5 model-selector dismissal fix is independent of DSH 0.1.2-alpha.1.
