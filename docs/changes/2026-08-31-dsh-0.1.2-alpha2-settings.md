# Resource Management 0.3.6 — DSH 0.1.2-alpha.2 Settings migration

DSH 0.1.2-alpha.2 removed the runtime `settingsNamespace()` helper. Resource
Management now reuses the validated namespace identifier returned by
`ctx.settings.describe()` when it calls `mutate()`, rather than reparsing the
panel's string binding through the deleted helper.

The development baseline now uses the npm-published Alpha.2 Settings, LLM, and
invariant packages. Runtime peers remain open so Maintenance can continue to
test experimental plugin combinations without package-manager version gates.
